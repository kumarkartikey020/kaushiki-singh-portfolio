## 🚀 How to Run Locally

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Local Web Server
You can launch a lightweight local server using Node:
```bash
npx serve .
```
Or with Python:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

## 🌐 How to Deploy to GitHub Pages (Free)

1. Create a new GitHub repository named `kaushiki-singh-portfolio` or `<your-username>.github.io`.
2. Push `index.html`, `styles.css`, and `script.js` to your repository:
   ```bash
   git init
   git add index.html styles.css script.js README.md
   git commit -m "Initial release of Kaushiki Singh forensic portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** -> **Pages**.
   - Under **Build and deployment**, select **Deploy from a branch**.
   - Select Branch: `main` / `root` and click **Save**.
4. In under 60 seconds, your site is live worldwide at `https://<your-username>.github.io/<your-repo-name>/`!
